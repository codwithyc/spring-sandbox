# spring-sandbox

> **“생산성 있는 개발자”가 아닌, “문제 해결 중심의 백엔드 개발자”가 되기 위해.**

이 레포지토리는 단순한 기술 습득이 아니라, **현업에서 진짜 필요한 역량**을 쌓기 위한 학습 공간입니다.  
스프링 생태계를 기반으로 하여 다음과 같은 목표를 지향합니다:

- **생산성 강화**  
  스프링 프레임워크의 장점을 극대화하여 실제 프로젝트에서 빠르고 안정적인 개발이 가능하도록 연습합니다.

- **실력 증명**  
  단순 구현이 아닌 *“왜 이렇게 설계했는가”* 를 항상 질문하며, 성능 지표 및 정량적 수치를 통해 학습 결과를 명확하게 보여줄 수 있는 구조를 지향합니다.

- **대표 문제 해결력 강화**  
  N+1 문제, 트랜잭션 전파, 예외 처리, 커넥션 풀 튜닝 등 실제 업무에서 빈번하게 접하는 이슈들을 **기록하고 해결하는 문서 기반의 실험**을 수행합니다.

- **사고 중심 학습**  
  답을 바로 찾기보다는, *왜 이게 최선인지*, *어떤 대안이 있었는지* 스스로 질문하고, 선택한 방식의 장단점을 고민합니다.

---
LLM(GPT, Claude 등)에 의존하는 것이 아니라,  
**내 손으로 문제를 파악하고, 설계하고, 구현하고, 설명할 수 있는 백엔드 개발자**가 되기 위한 여정을 이 레포에 담고자 합니다.

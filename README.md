# spring-sandbox

spring-sandbox는 Spring 생태계를 기반으로  
백엔드 개발에 필요한 개념, 설계 판단, 문제 해결 과정을 실험하고 검증하는 개인 연구형 레포지토리입니다.

이 레포는 하나의 완성형 서비스를 만드는 프로젝트가 아니라,  
실무에서 반복적으로 마주치는 기술적 주제를 분리하여 코드, 테스트, 문서를 통해 검증 가능한 형태로 축적하는 데 목적이 있습니다.

## Scope

- Spring Core 및 주요 추상화
- Bean, DI, AOP, Transaction
- 예외 처리 및 공통 응답 설계
- JPA, 영속성 컨텍스트, Lazy Loading, N+1
- 커넥션 풀, 캐시, 동시성, 성능 이슈
- 테스트 코드 기반 검증
- ADR 및 문서 기반 설계 기록

## Approach

각 주제는 다음 흐름을 기준으로 다룹니다.

1. 개념과 문제 상황을 정의합니다.
2. 공식 문서와 레퍼런스를 통해 기준을 확인합니다.
3. 예제 코드와 테스트로 동작을 검증합니다.
4. 선택한 방식의 근거와 한계를 문서로 기록합니다.

## Principle

LLM은 탐색과 정리의 보조 도구로 활용하되,  
최종 판단은 공식 문서, 직접 실험, 재설명 가능성을 기준으로 검증합니다.

이 레포는 단순한 구현 기록이 아니라,  
왜 이 설계를 선택했는지 설명할 수 있는 백엔드 엔지니어링 기반을 축적하기 위한 저장소입니다.
